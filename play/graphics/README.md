# Vektör 1.1.0 görselleri

icon-512.png ve feature-1024x500.png yeni özgün Vektör kimliğidir. Düzenlenebilir SVG kaynakları assets/vektor altındadır. PNG çıktıları sistemin librsvg/Cairo kütüphaneleriyle oluşturulur; uygulamaya bir bağımlılık eklenmez.

Ekran görüntüleri imzalı uygulamanın QA emülatöründen alınır; test oyunu kullanıcı atamalarını temsil etmez. Eski Rota görselleri docs/history/Rota-1.0.2-store-graphics altında arşivlenmiştir. Console’a gönderim yapılmamıştır.
